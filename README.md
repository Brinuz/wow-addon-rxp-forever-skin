# RestedXP Forever Skin

Makes the **RestedXP Guides** window on **World of Warcraft: Forever** look like Blizzard's own windows. Built entirely from Blizzard's own UI.

## Features

- Blizzard's window frame and gold title, with the guide name in the title strip
- The step list as professions list rows, spaced apart with dividers, the current step highlighted
- Finished steps clearly marked: a checkmark, gray text and faded
- A "Current Steps" window for the active steps and tips, with gold step titles and Blizzard check boxes
- Active Targets docked as a row at the bottom of Current Steps, with action button art
- The waypoint arrow in Blizzard gold, with the step's main line between the step number and the distance
- Blizzard's thin scroll bar and settings icon
- RestedXP's settings and theme are never changed; turn the skin off anytime

Styles RestedXP's standard guide window. If RestedXP's V2 interface is turned on, the skin stays out of the way.

## Install

Requires RestedXP Guides. Copy the `RXPForeverSkin` folder to `World of Warcraft/_forever_/Interface/AddOns/`.

## Usage

| Command | |
| --- | --- |
| `/rfs` | Turn the skin on or off (off asks to reload) |
| `/rfs options` | Open the settings |
| `/rfs debug` | Print diagnostics |
| `/rfs mem` | Print memory use before and after a garbage collection |
